R3 SELLS WEBSITE — FREE STATIC SITE

1. Preview: Open index.html in a browser (or use a local static file server).
2. Edit products: Open products.js in a text editor. Change the name, category, details and image fields. Add more product objects by copying an existing entry. Keep commas between entries.
3. Add photos: Put images in the assets folder and reference them as assets/your-photo.jpg in products.js.
4. Edit words, Instagram and phone: index.html. The product-specific SMS number is also in script.js.
5. Change colors/layout: style.css.
6. Publish free: Create a GitHub repository, upload ALL files (including assets folder), go to Settings > Pages > Deploy from a branch > main / root > Save. Your site will have a free github.io address.

IMPORTANT: The product names and imagery are SAMPLE CONCEPT CONTENT, not verified real inventory. Replace them with your own photos and listings before sharing with customers. The phone number is visible publicly on the website. Prices are intentionally hidden. No online checkout or database is included.
